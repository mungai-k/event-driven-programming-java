# Procedural vs. Event-Driven Comparison

| Aspect | Procedural | Event-Driven |
|---|---|---|
| Flow Control | Program controls execution order step-by-step | User actions control execution flow via events |
| User Flexibility | Fixed order of inputs required | Interactions occur in any order |
| Execution Paths | Single sequential path | Infinite event-driven paths |
| Code Organization | Single linear procedure (`main` loop) | Decoupled component event handlers |
| User Experience | Rigid terminal prompt sequence | Interactive graphical user interface (GUI) |
